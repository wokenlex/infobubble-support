Exporting news

Send matching news to an RSS file, a CSV, your own API or a Telegram channel.

Each tab can export its news. Open the Export tab in the inspector and press Choose Export Method.

RSS FeedWrites an RSS file you choose with Select File…. Point a website or another reader at it.
CSV FileWrites rows to a spreadsheet file: title, link, date, summary, text, sentiment, tags, country, city.
API (POST Query)Sends each item as JSON to your API URL. Your server should answer {"status":"ok"}.
TelegramPosts to a channel through your bot: Bot Token and Channel ID / Chat ID (@channelname or -100…). Add the bot to the channel as an admin.

Options

  • Export automatically: every new match is sent. Otherwise right-click a news row → Export this news item, or drop rows onto the tab.
  • Translate: translate before sending.
  • Include summary: add a one-sentence summary written by the AI.
