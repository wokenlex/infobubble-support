# =============================================================================
# InfoBubble World RSS Database
# =============================================================================
#
# Structure: Country -> Category -> [RSS/Atom feed URLs]
# Categories are assigned loosely by AI and may be imprecise.
#
# Hostname databases used to discover the pages with news:
# the GDELT Project (https://www.gdeltproject.org) and the Tranco list
# (https://tranco-list.eu). See the Attribution section below.
#
# Sorting
# -------
# Within each category, feeds are ordered by the authority of their root
# domain, descending (most authoritative first). Authority is taken from the
# Majestic Million ranking of the top 1,000,000 websites by the number of
# referring subnets (a proxy for backlink-based domain trust). Feeds whose
# domain is not present in the Majestic Million are placed after the ranked
# ones, in arbitrary order.
#
# Source of the ranking: https://majestic.com/reports/majestic-million
#
